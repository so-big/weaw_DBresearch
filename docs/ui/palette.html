DBresearch color palette

The faculty maroon is the brand color, used sparingly so long document lists stay calm. A warm off-white base, one highlight color for focus and selection, a yellow search-hit marker, and status colors that never get confused with the maroon. 2 · Roles

What each color is for. The grays lean slightly toward the maroon, so the page doesn't look cold next to the brand color.

BasePage background (warm off-white). Easier on the eyes than pure white for long sessions.
SurfaceCards, list, forms, dialogs.
TextBody text. Muted gray for labels and dates.
PrimaryMain button, active nav, links, top strip. One primary button per screen.
HighlightKeyboard focus ring, active filter, expiry chip, "new" marker. Fill only, not text.
Search hitMatched words in search snippets (like this). Stays yellow whatever the highlight choice.

3 · Status colors

Each document status gets its own color plus a dot and a word, so nothing depends on color alone. The error color is an orange-red, far enough from the maroon that "failed" never looks like a brand element.

Do

Keep big maroon areas to the thin top strip and the one main button. Reuse the faculty site's maroon top bar idea, but slimmer.

Avoid

The faculty site's full maroon hero banner on working screens. It pushes the document list below the fold on a phone.

Do

On the guest share page (mostly phones), make the download button full width, maroon, and at least 48px tall.
